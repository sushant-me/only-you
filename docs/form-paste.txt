LONG DESCRIPTION (~230 words)
Your glasses can hear the world. Should they obey a TV ad? A poster? A look-alike invoice?
Meta's WebMCP documentation says the untrusted-content flag is "not an enforced security boundary," and
the assistant still cannot tell the wearer's voice from a stranger's. Once an agent has a camera, a
microphone and a wallet, a TV ad, a poster, a webpage or an invoice can issue commands.

ONLY YOU fixes the channel instead of asking the model to be robust. Before the model sees a token, every
input is labelled by provenance: on-device speaker verification, scene reading with Muse Wonder, DOM
origin, document trust. A deterministic constitution and signed, scoped, expiring mandates gate
irreversible actions (caps, per-merchant/daily sub-limits, recurring allowances, sub-agents that can only
narrow authority); every action and every refusal emits an HMAC hash-chained receipt with the rule, the
evidence and an undo. Mandates are signed with an Ed25519 device key, so a merchant can verify the owner's
delegation offline with only the public key.

The demo is a success, not a block: the owner delegates one payee and a cap, the agent pays an invoice
without interrupting, and a look-alike invoice with the same spoken command is refused because its payee
came from a document. A poster, a TV ad and hidden page text are read but never obeyed.

We publish the numbers that can be wrong — three real Muse Spark runs, the confused-deputy corpus where
the undefended model pays 25% of the time and the full gate pays 0%, the label layer's recall and false
positives, and the adaptive attacks that still get through.
